# dotfiles

Personal configuration files for macOS and zsh.

## Contents

- `.zshrc` — shell aliases, prompt, and plugins
- `.gitconfig` — global git settings
- `.vimrc` — minimal vim tweaks

## Usage

Clone and symlink manually, or run `./install.sh` (coming soon).

## Notes

- Designed for zsh + oh-my-zsh.
- Aliases are grouped by topic in `.zshrc`.
- Comments explain non-obvious settings.
